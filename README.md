# Retail Sales Performance Analysis

## Project Overview
This project analyses retail sales transactions using Microsoft Excel to evaluate business performance across products, regions and salespeople.

## Business Objectives
- Determine total revenue and average transaction value.
- Identify the highest-revenue-generating products.
- Evaluate sales performance across different regions.
- Compare salesperson performance.
- Develop insights to support business decisions.

## Tools Used
- Microsoft Excel

## Methodology
1. Data inspection and cleaning.
2. Standardisation of inconsistent text entries.
3. Creation of calculated columns.
4. KPI calculations.
5. PivotTable analysis.
6. Dashboard development and visualisation.

## Key Performance Indicators

| Metric | Result |
|---|---:|
| Total Revenue | KES 4,341,272.00 |
| Total Transactions | 120 |
| Total Quantity Sold | 281 |
| Average Transaction Value | KES 36,177.27 |

## Key Findings
- Laptops generated the highest revenue among the analysed products.
- Mombasa recorded the highest transaction count, with 30 transactions.
- David generated the highest revenue at KES 1,175,392.
- Brian recorded the highest transaction count among salespeople, with 26 transactions.

## Recommendations
- Review the performance of high-revenue-generating products.
- Investigate factors contributing to Mombasa's transaction activity.
- Identify practices associated with strong salesperson performance.
- Monitor revenue, transaction volume and average transaction value together.
